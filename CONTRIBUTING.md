# Contributing to Nudgi

Thanks for helping make Nudgi better. Bug reports, ideas, docs fixes and code are all welcome.

## Ground rules

- Be kind and constructive. This project follows the [Code of Conduct](CODE_OF_CONDUCT.md).
- The buddy only says text the user configured. Please do not add hardcoded phrases to the bubble or voice;
  express moods and celebrations visually.
- Keep personal data out of the repository. Never commit personal avatar models (`*.glb` other than the bundled
  `kai.glb`), profiles or screenshots that show private information.
- Use plain hyphens (`-`) in text, not em or en dashes.

## Reporting bugs and requesting features

Use the [issue templates](https://github.com/vraj-p8/nudgi/issues/new/choose). For bugs, include your Windows
version, Nudgi version (shown in Settings), steps to reproduce, and what you expected.

## Development setup

Requirements: Windows 10 or 11 and Node.js 22 or later.

```powershell
npm ci
npm start          # run the app
npm run dev:web    # browser previews of the renderer pages at http://localhost:5178
```

The code is plain JavaScript: CommonJS in `src/main`, native ES modules in `src/renderer`, no bundler or framework.
Match the style of the surrounding code and keep comments short and useful.

## Before opening a pull request

1. `npm test` passes.
2. For behaviour changes, run the end-to-end checks that cover your area (each uses an isolated profile):

   ```powershell
   .\node_modules\.bin\electron.cmd scripts/audit.cjs
   .\node_modules\.bin\electron.cmd scripts/verify-desktop.cjs
   .\node_modules\.bin\electron.cmd scripts/verify-kai.cjs      # 2D Kai motion
   .\node_modules\.bin\electron.cmd scripts/verify-avatar.cjs   # 3D motion and props
   .\node_modules\.bin\electron.cmd scripts/verify-click.cjs    # real mouse input on the bubble (moves your cursor)
   ```

3. Animation or UI changes include a screenshot or short clip in the pull request.
4. User-visible changes get a line under an "Unreleased" heading in [CHANGELOG.md](CHANGELOG.md).

## Changing 3D Kai

Kai's model is generated by `scripts/build-kai.py` (Blender 5.2):

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" --background --factory-startup --python scripts/build-kai.py
```

It writes `src/renderer/shared/avatars/models/kai.glb` and preview renders to `output/kai3d/`. Keep the
52-bone T-pose skeleton and bone names; the 3D engine depends on them.

## Releases

Maintainers bump the version in `package.json`, update the changelog, run `npm run build`, and publish the
installer, portable EXE and `SHA256SUMS.txt` as a GitHub release.
